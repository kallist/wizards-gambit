# 巫师棋：与马尔福的甜蜜生活

成年返校 AU 同人魔法国际象棋：剧情、人机、同机双人、好友房间，以及可切换的 2D/3D 棋盘。马尔福的立绘互动与棋局规则分离。

新增“今晚棋旅”有限样章：邀请与两种整程准备→三个真正将死的短局→一次递／接茶→归家星纹杯垫。三张魔法整程共用，选择后两局的顺序；全程一次重试，再败归家，练习不领奖。棋盘与高清全身魔镜共用暖色棋桌，手机保留头像与可展开全身镜。杯垫记住实际递茶方向、收棋与帮助，下次邀请会回指这一晚。此为三节点原型，尚不是正式4–5场、15–25分钟的一程，也没有证明复玩吸引力。实现、评审与验收见 [v12交付记录](docs/planning/delivery-report-v12.md)。

完整玩家存档内容现为schema 3，包含独立棋旅；旧schema 2自动迁移并保留旧棋局。文件封装仍为version 2。没有Web Locks时，普通本机／访客使用从原件复制的页面私有临时会话；所有临时写入与原持久档隔离，设置可分别导出临时档与原件。**临时会话刷新／关闭前未导出的新进度会丢失**。账号云存档仍要求安全锁和可验证身份，不承诺任意条件永久无损。

## 本机游玩

Windows双击项目根目录的 **`开始游戏.cmd`**，会启动仅本机可访问的服务并自动打开 **http://localhost:8787/**。启动窗口保持打开；重复启动复用同一游戏服务。不要双击源码或dist中的`index.html`：源码需要编译，构建页面的ES模块／Worker也需要HTTP环境。直接打开HTML会显示启动说明。

首次从源码安装需要Node.js 22.12+及`npm ci`；缺少构建文件时启动器会执行`npm run build`。修改源码后请重新构建。也可运行`npm run play`启动已构建版本。启动器固定同一地址，端口被其他程序占用时明确报错，不自动换端口；浏览器存档按来源隔离，原先使用127.0.0.1或其他端口的玩家请继续用原地址并在设置导出备份。解压的Toy上传ZIP仅是静态资源包，不含Windows启动器，应通过HTTP托管或上传Toy后访问。

```sh
npm run typecheck

npx playwright install chromium
npm run test:e2e
npm run format:check
npm start
```

打开 **http://localhost:8787**。点击“进入游戏”放大像素小屋，再点击棋桌选择剧情、人机、同机双人和好友房间；人机设置中有魔法试炼。点击小屋里的马尔福可打开右侧高清人物聊天。点击马尔福立绘，每轮双人对白配有不同的实际表情；累计羞涩程度保留，达到计数上限后仍可继续换回应。对局右上切换 2D/3D。声音默认关闭，点喇叭启用；设置可减少动态效果。

温馨像素小屋与Three.js实时粒子银河：封面放大进入生活场景，棋桌进入星空棋盘，返回小屋保留同一棋局。默认像素 2D，可切换真实 3D 并自由旋转/缩放与战术复位。桌面/横屏右侧常驻高清全身人物；手机竖屏右上常驻头像，可展开完整人物。银河有星尘、旋臂与指针视差，对局时降低亮度，减少动态效果时静止。小屋可点击轻摆，炉火、暖窗、烟雾持续变化；全身魔镜同步选子、准备施法、思考、交接与已确认棋步。心动、羞涩与内心想法独立于棋局。

衣橱共 24 套成年衣装，初始拥有两套，另外 22 套通过正常终局或章节目标等概率收集，同一局最多一次。每套有八种实际绘制的表情差分（共 192 幅，按 3＋3＋2 帧保存于 72 张透明图集），以及一张专属双人 CG、24 页番外和两处对话选择。运行时加载 WebP；PNG 原稿完整保留在作者本机，按上传范围不纳入此公开源码仓库，运行与构建均不依赖PNG。CG 与衣装同步解锁；番外单独展示双人 CG，第24页读完点击“读完了”返回衣橱，保留“从头阅读”和已保存选择。原六章主线保留。声音默认关闭，启用后播放原创柔和配乐；设置可调配乐音量与减少动态效果。

标题、主按钮和人物姓名使用随包提供的Ma Shan Zheng书写字体（SIL OFL 1.1），正文保持阅读字体。六章120组互动与番外部分对白已重新润色，全部为本项目原创成年AU文本；来源、字体许可、验证与限制见 [对白与字形v7](docs/dialogue-and-lettering-v7.md)。

衣橱与领取账本一次写入本机存储。Toy入口点击“连接B站存档”授权后，按OpenID散列隔离本机数据，先恢复再进入游戏；普通浏览器继续使用原本机档。章节、互动、最高分、衣装、心动、领取账本、番外位置/选择、个人设置和非联网棋局均纳入完整备份。变化在本机标记待同步，短时间连续变化合并上传，断网后重试并保留待同步状态；设置提供文件导出/导入、旧本机档/访客档明确合并和云端棋局恢复。旧未归属本机档不会自动上传到当前账号。详见 [玩家存档v8](docs/player-save-v8.md)。

云端采用分片校验后发布的不可变备份，每设备保留两份可用快照，只清理自己的旧数据；核心进度取较高值、衣装取并集，不自动替换当前设备的活跃棋局。同源同账号使用Web Locks限制为一个游玩窗口；缺少安全锁/OpenID或云空间不足时提供本机访客与文件备份，不冒险上传。好友房间凭据仅保存在所属账号本机，不进云或导出文件。平台没有公开事务/CAS或可靠切号事件，不能保证所有条件下永久无损，个人收藏也不提供竞技反作弊。原美术范围见 [像素小屋设计](docs/pixel-room-ui-brief.md)、[美术记录](docs/art-direction.md)。

生产服务监听 `0.0.0.0:8787`，提供静态页面、`GET /api/health` 与 `/socket`。同一局域网内的另一台设备可以用电脑的 LAN IP 加入；本轮没有做物理跨设备实测。公网需要 HTTPS/WSS 反向代理，并通过 `ALLOWED_ORIGINS` 明确设置可信页面来源。可参考 `.env.example`；前端环境变量都是公开配置，不能放凭据。

房间为有界内存状态，断线保留座位五分钟，服务器重启后不恢复。不支持多实例共享房间。两端准备后开局，服务端确认操作并裁剪未知手牌；刷新后可恢复上次座位。剧情、棋局和本机纪录保存在当前浏览器。

## Toy 上传包

```sh
npm run build:toy
npm run verify:toy
```

上传 `dist-toy/` 的内容，入口 `index.html` 放在包根。Windows 可运行 `powershell -NoProfile -File scripts/package-toy.ps1`，ZIP 输出至 `.local/wizards-gambit-toy.zip`。这只是构建与打包，不会自动上传或发布。

Toy 构建开启官方 SDK 适配；普通浏览器展示明确标识的本机纪录。好友房间需要另外部署 Node 服务，构建前设置 `VITE_ROOM_SERVER` 为公开 WSS 地址，并完成平台的 `external_service_access` 域名审核。没有配置的 Toy 包会明确提示好友棋室尚未开放；其余本地模式可游玩。

存档v8的账号隔离及完整保存/恢复已有隔离SDK Mock与自动化Chromium证据。2026-10-21审查发现的普通本机多标签核心进度覆盖和异常WebSocket地址问题，已在v12有限样章阶段修复并重新验证；早期“修复未完成”的评委记录保留为历史。2026-10-24上传GitHub前重新执行生产构建（含类型检查）、130项单元测试与格式检查，均通过。后续启动入口与收藏栏修复见 [本机游玩说明](docs/local-play.md)、[左侧收藏栏记录](docs/cottage-sidebar.md)；完整工程与尚未完成的门槛见 [v12交付记录](docs/planning/delivery-report-v12.md)。

2026-10-22官方CLI只读身份查询成功，已不再以10月18日的白名单拒绝作为当前阻塞依据。CLI身份可用不等于作品上传、容器或云端验收通过；真实Toy云榜、云存档、外部WSS和B站App仍未验证，也未提交审核。发布者还需启用Toy OpenID模式并完成真实容器验收。详见 [Toy运行与存档核对](docs/toy-save-readiness.md)、[Toy接入说明](docs/toy-and-game-feel.md)。

素材维护（需另备PNG原稿，公开仓库仅提供运行WebP）：`scripts/export-art.py` 按用户授权另导出 WebP，并通过临时文件完成后替换目标；`python scripts/verify-art.py` 只读检查作者本机保留的98对源稿和14对新增/修复稿（共112对）的解码、透明通道、尺寸与哈希。`scripts/measure-outfit-frames.py` 从全图主体生成192帧的显示轮廓，恢复越过分格线的鞋尖并排除邻帧碎片；不修改图片，人物源图粘连时会拒绝生成。验证/导出需要 Pillow，轮廓测量还需要 NumPy，运行游戏不依赖 Python。源码上传范围见 [GitHub源码说明](docs/github-source.md)。

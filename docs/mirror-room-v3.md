## 架构与计划

当前为 React/TS/Vite、Three.js 绘制、纯领域规则、AI Worker、Node 权威好友房间与 Toy 适配。新建独立陪伴/衣装模型与 `MirrorCompanion`，复用棋局引擎和协议；移除场内透明人物及近景锁棋，OrbitControls 不再被每帧机位插值覆盖。

影响 `src/App.tsx`、`src/ui`、`src/renderers`、`src/platform/toy.ts`、`src/story` 的陪伴模型，以及素材、音频、样式和测试。正常终局以持久对局 ID 领取；本机一次写入同时保存新衣装和领取记录，支持的浏览器串行化多标签读改写。存储失败不宣称永久解锁。Toy 云存档只同步紧凑衣装集合/心动和原进度，合并保留本机账本，兼容旧存档。客户端收集存档不称反作弊系统。

主要风险：素材体积与懒加载、192 张差分一致性/解剖、手机镜框占位、自由镜头的手势误落子与穿模、奖励重复/存储失败/云合并、音频用户手势与循环衔接。标准规则、技能强度、房间部署架构、公开匹配与发布不在本轮范围。

验证：既有规则/房间/Toy 回归；新增终局奖励、重复领取、旧存档迁移、并发与失败测试；实际相机拖动/复位/走棋、2D/3D 同镜框、真实差分载入、衣柜解锁与刷新、手机布局、音乐播放/关闭/音量；生产与 Toy 构建、嵌套路径检查、ZIP 对照、人工图像/界面自查。原生手机/真实 Toy/主观听感另列。

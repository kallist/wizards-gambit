# 人物展示移入魔镜，3D 恢复主动自由观察

用户明确否定场内透明人物的纸片观感，并要求恢复自由旋转。2D/3D 因而共用独立全身魔镜界面，人物不再加入世界场景或限定相机绕背。相机允许主动旋转和缩放，同时保留战术复位、距离/俯仰限制与舒适模式。代价是失去人物和棋桌的世界遮挡关系，换来稳定清晰的角色表现、统一互动与自由镜头。

衣装收集和心动归于独立陪伴进度，以持久对局身份防重复领取，不污染棋局随机源、领域引擎或服务端房间协议。浏览器存档能够被设备所有者修改，Toy 云写入也无事务/CAS，因此明确定位为个人收集而非竞技防作弊资产。旧进度向后兼容，领取账本保留本机；存储失败不宣告永久奖励。

# 0005 · 点击回应驱动当下神态，保留长期亲近进度

状态：已接受。日期：2026-10-18。

## 背景

累计taps与legacy frame分别承担长期羞涩程度和棋局事件映射。把点击后的图片仅交给阶段默认值，会让同阶段和后期对白换了、神态却不变；100000封顶后，按taps取词也会固定。legacy frame的编号不是实际八差分编号，直接改映射会影响原棋局事件。

## 决策

点击回应显式绑定台词ID、双方短对白与实际Expression。独立的非持久游标轮换，同阶段也排除上一张神态；保留taps的阶段阈值、封顶与存档契约，不消费棋局随机源。小屋魔镜、对局魔镜与手机头像使用同一瞬时神态；常规聊天、棋局回应和重新开局清除覆盖。取消旧表情计时器，避免它干扰新回应。

界面文字采用本地OFL书写字体，正文继续使用阅读字体。窄屏短状态由真实局面分支与完整状态一起产生，不从人类可读句子解析；人物称呼在显示时保持不拆行。运行时仍为预写对话，不引入LLM、API、数据库或新依赖。

## 影响与证据

刷新保留长期亲近程度，瞬时反应不写入存档。轮换池有限，允许隔若干次再出现相同回应，相邻点击必须换神态与台词。字体缺失回退现有字体，版权许可随包提供。验证与限制见 [v7交付记录](../dialogue-and-lettering-v7.md)。

# 银河与全身镜 UI 深化（v5）

2026-10-18 · 用户直接要求参考知名独立游戏、把背景改成银河、给马尔福聊天增加全身镜。保留已确认像素小屋、高清人物、2D默认/3D可切换、预写聊天与移动陪伴。

北极星：在有星云与暗尘纹理的银河里，两人小屋亮着暖光；走近她时，一面银绿古镜承载完整人物，手札式对白从镜旁展开。

## 当前架构与实施计划

React/TypeScript呈现层，Three.js分别管理实时银河与棋盘，人物使用已修复SVG图集。最终只采用一张全身镜素材；用户随后明确要求实时银河，早期两张生成的银河概念图未采用、不进入包。保留棋规、AI、奖励、存档schema、协议和平台部署。

1. 实时银河：Three.js三维旋臂粒子、程序着色器星云/暗尘/亮核；按半径旋转、闪烁与指针视差。桌面/竖屏分别调观察角，保留舒适模式、隐藏暂停、软件渲染像素预算和单帧GPU栅栏。银河不用位图。
2. 实体全身镜：独立生成古银/旧黄铜/祖母绿镜框与暗镜面图；图层放在人物后方，角色视口留安全边距，姓名与对白在镜外。聊天和对局陪伴复用同一镜组件。
3. UI器物感：封面标题与主按钮、场景入口、对局工具、人物对白、衣橱弹窗采用统一金属切角、银绿浮雕、墨紫深底与象牙字。避免把所有区域套进重复外框。
4. 横屏聊天改为镜子与对白相邻，以免再次把人物挤成100px；竖屏完整人物与对白上下分区。
5. 类型/格式/生产与Toy构建，相关UI行为与失败/存档回归；银河实际绘制与舒适模式，镜框头脚安全区/遮挡像素，三个目标视口与2倍图、动效记录、隔离独立视觉评审。

风险：镜框遮人、姓名挡脚、宽衣摆超出内沿；手机银河过度裁切；画面过亮遮棋格；短屏对白/按钮溢出。逐项用实图与真实交互核查。可逆UI取舍不新增ADR。

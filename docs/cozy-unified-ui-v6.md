# 星夜约棋：统一画面与温馨小屋（v6）

北极星：银河中的两人小屋，把炉火、木质棋桌、银绿魔镜与手札对白连成同一个温暖的约棋空间。

用户已确定像素场景、高清人物、实时可动银河、可点击小屋、全身镜、默认2D与可切换3D，本轮深化这些决定，不重开风格选择。

## 架构与计划

- 当前：React呈现层；Three.js实时银河与3D棋盘分开管理；2D棋盘沿用棋规模型；人物使用192帧的轮廓图集；收藏持久化独立。
- 影响：TitleScreen、MirrorCompanion、App的展示接线、pixel-ui.css、小屋新版本资产、行为回归。
- 设计：移除陪伴区的大矩形外框，镜、暖光、手札对白直接进入银河画布；棋盘改为木质黄铜镶边的棋具，控件与手牌采用同一旧金属/墨绿/暖纸材质；小屋增加柔软织物、双人生活细节和集中暖光。人物反应沿用已有棋局事件，补足可读上下文。
- 风险：装饰影响落子；镜框挤压人物；手机短屏对白溢出；新增材质影响棋色辨识；新小屋人物/棋桌位置改变使热点失准。
- 验证：类型、格式、生产/Toy构建、素材原稿与导出哈希、相关行为回归、全套E2E、三比例实图与2倍图、独立视觉评审。所有交互仍由HTML/真实棋局驱动。
- 范围：不改棋规、AI搜索、抽卡、收藏schema、服务端协议、部署，不声称新增3D建筑或行走角色。

# 巫师棋：与马尔福的甜蜜生活 · 当前UI

2026-10-18 · v6。北极星：银河中的两人小屋，把炉火、木质棋桌、银绿魔镜与手札对白连成温暖的约棋空间。

## 已确定方向与真实交互

像素场景、高清人物、默认像素2D与可切换3D、预写聊天、竖屏常驻头像/横屏完整右栏均由用户确认。最新要求深化温馨、整体UI与人物联动，不重开风格选择。研究参考见 [v6深化](cozy-unified-ui-v6.md)、[银河与镜子](galaxy-mirror-ui-v5.md)。

封面“进入游戏”或点击小屋走近，不创建棋局。点人物展开全身魔镜、双人对白与三个话题；点棋桌打开继续/故事/人机/同机/好友，人机设置保留试炼。衣橱/手札/画廊/图鉴在边缘短菜单。进入对局建筑退出，只留银河中的棋具、手牌和陪伴；返回小屋、刷新继续同一局。离开本地对局暂停AI搜索，在线订阅继续工作，不把在线对局伪装暂停。

魔镜只读呈现当前选中棋子、准备中的本方魔法、思考/交接与已确认公开棋步。聊天覆盖情境对白，已确认棋步仍在，点击人物和展开心事都不改变GameState、手牌、随机源或领取账本。心事折叠在对白后；和局不说败局，同机结果明确白/黑方。

## 视觉与设备

木质黄铜盘沿、暖纸手牌、墨绿手札式对白和银绿实体镜统一材质。陪伴区移除大矩形外框，暖光与银河贯穿两侧。标题/主按钮/姓名使用随包提供的Ma Shan Zheng书写字体（OFL 1.1），楷体/宋体回退；正文微软雅黑/系统字体。字形不改变高清人物与像素小屋的混合方向。盘面实色、坐标与合法目标可读，装饰不接收指针。

桌面陪伴区320–440px；镜子2:3原比例按容器完整适配，姓名与对白在镜外。390×844竖屏常驻头像与简短状态，点击展开全身魔镜。844×390横屏陪伴区280px，镜与双人对白并排，棋盘左置、三牌纵置；保留原有不遮棋格与不裁牌的约束。

银河用Three.js三维粒子与程序星云着色器，正常23260/软件12260粒子；按半径旋转、闪烁、指针视差，对局亮度48%。随机源独立棋局。减少动态时静止、隐藏时停调度；普通110万/软件40万像素、DPR≤1.5，调度受限并不堆积GPU请求，不宣称实机达到目标帧率。

小屋800ms首次出现、450ms走近/让位、300ms聊天展开、250ms棋局菜单，轻缓悬浮/炉火/暖窗/烟雾和650ms点击轻摆；新对白300ms响应。按钮有按压/聚焦，既有落子/魔法/击毁反馈保留。舒适模式关装饰运动但玩法、状态文字照常；没有新增3D飞行镜头。

App home/room/game分离生活场景与棋局模式。TitleScreen管理人物/棋桌面板；Three.js背景与棋盘独立生命周期，异步加载取消、隐藏停帧、卸载释放资源。无新API/DB/schema/依赖/运行时LLM。原规则、AI、奖励概率、协议、配乐与Toy适配保留，未发布或上传。

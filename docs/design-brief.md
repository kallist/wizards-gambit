# 巫师棋：与马尔福的甜蜜生活

2026-10-18 · v7：温馨像素小屋、实时银河与全身魔镜，深化逐句神态、对白与书写字形。上一版设计事实保存在 [v4记录](planning/design-brief-pixel-v4.md)。

## 玩家体验

成年23岁返校AU，女性马尔福为陪伴主角。暖光小屋漂浮在实时银河里，两人在屋内下棋。点击进入走近小屋，点人物聊聊，点棋桌开始或继续棋局；建筑退出后，棋盘与全身魔镜共同悬于银河。

默认像素2D，保留真实3D与自由相机/复位。桌面和横屏常驻完整魔镜，手机竖屏常驻头像与简短棋局状态，可展开全身人物。聊天采用预写话题与回应，运行时不调用语言模型。

## 融合与范围

木质黄铜盘沿、暖纸手牌、墨绿手札式对白和银绿魔镜共享光线与材质。陪伴区移除大矩形外框；当前选子、准备施法、思考、交接与公开棋步进入魔镜，事实和情境对白分开呈现。心事可展开。点击回应将实际八表情之一与双人台词绑定；同阶段不连用同一神态，100000封顶后仍轮换。常规聊天和棋局对白接管瞬时表情，保留长期羞涩程度；标题/主按钮与姓名采用本地OFL书写字体，正文保持阅读字体。和局、同机结果与换手头像采用准确身份文案。

原六章、24魔法、剧情/人机/同机/好友/试炼、24套衣装各8差分、24CG与番外、等概率收集、同局领取一次、自动存档、换手隐私、联网权威与未知手牌裁剪、主动启音和原创配乐全部保留。

React/TypeScript/Vite，规则在domain、AI在Worker、剧情与陪伴在story、Toy/存储/房间在platform，Node维护权威内存房间。只改呈现、场景导航、立绘几何和相关验证；不改棋规、AI搜索、奖励概率、存档schema、HTTP/WS协议或部署。无数据库、新依赖、运行时LLM或新密钥。

没有新增自由AI聊天、完整3D建筑/行走人物、公开匹配或竞技反作弊。未执行提交、推送、PR、发布、Toy上传。

# Toy发布说明

游戏的Toy交付物是`npm run build:toy`生成的静态资源，入口位于包根。它与GitHub源码仓库是不同交付物，不包含PNG原稿、Node好友服务、开发依赖或玩家存档。

首次发布使用游戏名称“巫师棋：与马尔福的甜蜜生活”，分类GAME，深色展示；地址标识建议沿用`wizards-gambit`。最终标识及可见性以用户确认的提交参数和平台记录为准。地址发布后不随标题变更。

发布按[官方Toy skill](https://github.com/bilibili/toy/blob/main/skills/toy/SKILL.md)执行：先运行当前官方内容预检，再上传取得试玩预览；用户检查并明确确认提交后，才提交审核。上传、审核中与已发布分别记录，不能以CLI上传成功推断已经对外上线。

2026-10-24预检复现了旧文档中的SVG纹理误报：内嵌data URL里的滤镜片段被扫描器误认作外部文件。现将片段中的括号规范为URL编码；解码后的SVG及隔离Chromium实际栅格像素完全一致。没有修改或跳过官方检查器。重新构建后，当前官方预检通过，含4:3实机封面检查；原交付报告中的ERROR保留为当时历史。

本次版本包含剧情、人机、同机双人、魔法棋与三节点棋旅，以及现有衣装、CG和互动。未配置公开`VITE_ROOM_SERVER`时，好友棋室按既有逻辑显示尚未开放。账号云存档仍需平台OpenID配置、玩家授权、安全存储能力及真实写入／恢复验证。SDK Mock不构成真实Toy云验证；共享云额度的实际负载表现同样未验证。正式发布前应检查手机横屏、声音、WebGL／Worker及存档入口。

实际预览链接、包哈希、平台响应、用户确认及审核结果保存在本机发布记录；本说明不写入会话凭据或未公开预览令牌。官方入口／包限额以当前平台返回为准，本项目继续用ZIP和展开体积均小于50MB作为保守预算。

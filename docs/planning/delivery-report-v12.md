## 本次结果

## 工程选择与数据边界

- `src/journey/catalog.ts`：三节点FEN、两套有限准备与不抽新牌的节点工厂。共享合法棋步、施法、王安全和结算。
- `src/journey/model.ts`／`storage.ts`：纯命令状态机；一次scope锁、预期revision和单JSON写入共同提交节点、卡、重试与生活记忆。重复命令幂等，过期操作读回，写入失败不推进画面。恢复棋盘需完整历史重放，允许先用同法术第二张卡，不信任任意外来字段。
- `JourneyController.tsx`：React仅编排已有Worker和领域命令；迟到AI回答检查旅程身份、节点、版本和生命周期，归家／跨页刷新取消旧请求。提示分王安全、原因与候选演示；不宣称Worker候选为最优解。
- `JourneyScreen.tsx`／`journey.css`／`JourneyKeepsake.tsx`：受控呈现、工具层级、阶段焦点／滚动、共同棋桌及杯垫。正文保持可读字体，主标题沿用现有随包书写字体。
- `src/platform/saveModel.ts`／`playerStorage.ts`：PlayerSave内容schema 3兼容旧schema 2；文件wrapper与云清单仍version 2。棋旅加入原本完整导出、导入、恢复日志和不可变云快照。旧普通棋局保留；合并不将另一设备的旅程强行拼接／覆盖本地活跃棋盘，完整云提交可明确恢复。见[ADR 0007](../adr/0007-journey-player-aggregate.md)。

杯垫按外观、结局和递茶方向最多18种首次图案来历，另存最近一晚作回指。重复游玩不无限增长背包，也不会被128晚之类的隐形总次数上限截断。测试覆盖140晚后仍保留首次与最新来历；不是将全部旧晚日志永久存档的承诺。

阶段0修复：异常WebSocket升级URL返回400并保持服务存活；普通本机／访客核心进度写入按scope安全锁重读合并，旧页轻触不覆盖较高进度。无安全锁时使用原档的页面私有临时副本，所有游戏写入与原持久档隔离，提供临时档与原件分别导出；刷新／关闭前未导出的临时变化仍会丢失。账号云存档仍需安全锁与可验证OpenID。

API变化：无；数据库变化：无；房间协议变化：无。安全影响为存档隔离与允许字段投影加强；房间token继续排除在云与导出之外。测试均用隔离浏览器和Mock账号，未接触真实玩家档案、凭据或既有8787服务。

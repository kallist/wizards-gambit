# 像素小屋、高清人物与可动银河

2026-10-18。成年23岁AU，游戏名为《巫师棋：与马尔福的甜蜜生活》。历史素材记录见 [v0.3美术记录](planning/art-direction-v3.md)。

## 当前素材与呈现

原创像素剖面石木小屋含上下两层、暖窗、壁炉与两人下棋的中心场景。采用参考的空间关系，不拷贝参考像素、建筑轮廓或巨型角色。小屋为透明PNG与无损WebP，银河由代码实时绘制。

人物保持高清动漫立绘。24套衣装、每套8种表情，共192幅，以72张3＋3＋2图集供运行选择；24张衣装专属CG、原六张主线CG及魔法插图保留。表情为傲娇、浅羞、明显害羞、眨眼、欢笑、气鼓鼓、担心、温柔。

旧图集某些人物越过分格边界或源图互相粘连。学院/晚宴/香槟各三张和魔女首图共10张经内置image_gen编辑修复，全身完整分离；旧源稿全部保留。其余图集复用原稿，显示采用主体轮廓包络，排除邻帧碎片并恢复鞋尖/裙摆。没有用滤镜伪造八种表情。

全部旧98对素材与新增11对素材共109对，验证脚本检查解码、透明通道、尺寸、字节数和SHA256。运行图集仍72张，不能把保留原稿与修复稿重复计为新衣装。生成图的手指、布纹与姿势有细微变化，不宣称逐像素一致。

新素材/提示词/编辑来源与哈希见 [v4清单](assets-v4-manifest.json)，原始完整素材见 [v3清单](assets-v3-expanded-manifest.json)。所有导出保留PNG源稿，使用用户授权的WebP流程；游戏运行不依赖Python。

## 银河与3D

四条星尘旋臂、偏置星核、星云与远近星点构成层次，慢旋转、漂移、闪烁与指针视差提供太空感。进入棋局减弱亮度，舒适模式静止，隐藏页面暂停调度。3D只保留棋盘/棋子及外围暗星，旧宿舍家具不再加载；不声称为完整三维宇宙模拟。

桌面、手机、横屏状态及192帧实际衣橱联系表见交付报告列出的本地证据。真实手机触摸/GPU、正常速度动效主观手感分别标注，不由静帧推断。

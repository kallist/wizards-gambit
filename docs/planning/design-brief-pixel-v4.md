# 巫师棋：与马尔福的甜蜜生活

2026-10-18 · 当前像素小屋与星空界面。上一版事实保存在 [v0.3设计记录](planning/design-brief-v3.md)。

## 玩家体验

成年23岁返校AU，女性马尔福为陪伴主角。像素小屋漂浮在可动银河里，两人在屋内棋桌旁相对而坐。进入游戏走近小屋，点她聊天、点棋桌开始或继续棋局；对局独立悬于太空，右侧高清人物持续在场。

默认像素2D棋盘，保留真实3D与自由相机/复位。桌面和横屏显示完整右栏，手机竖屏保持头像并可展开完整人物。聊天采用预写话题与回应，运行时不调用语言模型。

## 保留的游戏

六章主线、标准棋规则与24张魔法牌，剧情、人机、同机双人、好友联网及固定试炼。24套成年衣装，每套8种实际绘制差分、一张双人CG、24页番外及两处选择；正常终局/章节目标收集未拥有衣装，同局一次，认输、退出和断线不领取。心动、表情与收藏独立于棋局随机源。

自动存档、同机换手隐私、联网服务端权威与未知手牌裁剪、原创WebAudio配乐和主动启音保留。PNG源稿保留，运行加载WebP。Toy榜单与备份适配保留，普通浏览器明确展示本机纪录。

## 架构与范围

React/TypeScript/Vite；Three.js延迟加载。规则在src/domain，AI在Worker，剧情/陪伴在src/story，Toy/本机存储/房间在src/platform，Node服务维护权威房间。

本轮只改变展示、场景导航、立绘几何和相关UI验证；不改棋规、技能强度、AI搜索、奖励概率、存档schema、HTTP/WebSocket协议或部署架构。没有数据库、新依赖、运行时模型调用或第三方密钥。

没有新增自由AI聊天、完整三维人物、电影录音、公开匹配或竞技反作弊；返龄稿按用户要求略过。未执行提交、推送、PR、发布或Toy上传。

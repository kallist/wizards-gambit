# 巫师棋 · 将你入心

2026-10-16 · 用户已批准初始方案，并授权完成游戏。

## 已实现范围

- 明确成年返校 AU，女性马尔福为视觉主角。六章从重逢、互怼、暧昧、告白写到交往与并肩作战；包含 120 组双人对白和六幅章节 CG。
- 立绘点击有五个递增情绪阶段，配合表情与哈利直球；独立于棋局、抽牌和成绩。
- 完整标准棋规则与 24 张魔法牌。每回合可选施法一次，再走一步棋；将死获胜，魔法不能直接针对国王。
- 剧情、人机、同机双人、真实好友房间四模式。人机下有固定试炼入口；同机用交接遮罩保护手牌。
- 同局 2D/3D 切换、翻转棋盘、减少动态效果、音效、规则说明、技能图鉴与本机自动存档。
- 3D 石雕几何棋子、起跳移动、击毁碎片、冲击环、暖光与轻震；2D 也有棋子破碎反馈。
- v0.2 全屏棋厅与短菜单、插图手牌、按需说明、世界坐标内的 2.5D 全身马尔福、固定战术/人物近景，以及六张独立新 CG/四张全身稿的画廊与学院/晚宴装束选择。
- Toy SDK 榜单、成绩、剧情云存档适配；普通浏览器明确显示本机纪录，不伪造公共榜单。

## 当前架构

React + TypeScript + Vite；Three.js 延迟加载。`src/domain` 保存领域规则，`src/ai` 在 Worker 中搜索，`src/story` 保存原创剧情及试炼规则，`src/platform` 隔离 Toy 与房间连接，`server` 保存权威房间状态。

初次目录没有代码、Git、README 或现成架构。当前分支为 `feat/wizard-chess`，尚未提交，无 base SHA。新增 HTTP 静态服务、健康检查与 WebSocket 协议，没有数据库或运行时模型调用。

## 实现边界

- 等概率指共同牌池排除已持有牌后均匀抽取，没有稀有度权重；不宣称所有技能已经精确等强。
- 三档 AI 是本地有限搜索，试炼使用固定搜索候选；不宣称大师棋力。
- 同机隐藏是交接隐私；设备所有者可检查本机存储。联网通过服务端裁剪未知手牌。
- 房间短暂断线可重连；内存服务重启后不保留房间。真实公网、Toy 和手机实机仍需独立验证。
- 真人配音、战报图片分享、公开匹配、竞技段位、协商和棋未进入本版。装束为学院/晚宴两个选项；没有三套服装或完整三维角色模型。
- 当前未执行登录、Toy 上传、提交审核、部署、Git 推送或 PR。

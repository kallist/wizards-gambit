## 自查与修正

已修正：三手立绘；首页无障碍标题/图鉴入口；近景切 2D 后锁棋；近景对白无法手动关闭与过早自动消失；平面格子受棋子内容影响而高度不一；横屏交接遮罩与页面层级；场内人物透明边界点击；雕像本体点击命中；静态场景绘制开销与 GPU 队列堆积。静态几何按材质合并、动态阴影按变化更新，最多一个未完成 GPU 帧。没有更改领域规则、房间协议或技能强度。

3D 棋子为风格化程序雕像，人物为 2.5D 平面；没有冒充电影资产或完整三维角色。最终检查未发现未解决的 BLOCKING/IMPORTANT 项；本地验收通过，不升级为真实平台、真人审美或手机实机验收。

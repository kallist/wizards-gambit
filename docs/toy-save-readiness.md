| 章节解锁/位置、互动次数、试炼最高分          | 自动                 | 包含            |

“完整”只指表中明确纳入的数据，不代表所有设备实时同步或永久无损。当前设备保留已有棋局和偏好；新设备从云恢复，其他云端棋局可在设置中明确选择。音频启用开关继续每次由玩家主动打开。

## 当前行为

Toy首次及重新进入时，点击“连接B站存档”获得可验证的toyOpenId；发布者必须启用OpenID模式。资料接口没有公开静默授权参数，未获得身份不猜测账号。连接成功后先读云、合并及恢复，再挂载游戏，避免初始值先上传。账号本机数据隔离，旧未归属档与访客档需要玩家明确合并；原键保留。普通浏览器继续使用原本机档。

本机变化先持久化待同步标记。连续变化合并上传，自动尝试间至少5秒；失败指数退避至60秒，联网/重新连接或手动可重试。完整云提交先写压缩分片、读回校验，再写不可变清单并读回确认。每设备保留两份已校验的完整快照；清理仅针对自己的旧提交和孤立分片。若云读取失败、清单全部损坏或空间不足，保留待同步、本机数据和文件备份入口，不宣称完整同步成功。

章节解锁、互动、最高分与心动取较高值，衣装与领取记录取并集；同套番外取较新阅读记录，包括主动重读后的较小页码。同源同账号仅允许一个连接的游玩窗口，防止本机多键恢复与正在游玩的标签互相覆盖。设置支持导出/导入、云端合并、恢复其他云棋局及回到合并前副本。损坏本机档先保留原件，提供原件导出与验证过的文件修复；本机多键恢复有可重放日志。

云格式为v2，旧progress_v1只在新流程中读取兼容，不再由App写入。没有账号后端或数据库改造；房间协议、棋规、AI和美术范围保持原样。源码及测试见platform/playerStorage、saveModel、cloudSnapshots、SaveManager、SaveBoundary，以及player-save单元/浏览器回归。

## 证据边界与剩余限制

- 单元内存SDK及隔离自动化Chromium：覆盖原覆盖缺陷、并发设备、部分失败、损坏回退、配额、切号、完整备份和产品入口。它们是 **TESTED WITH MOCK / TESTED IN AUTOMATED CHROMIUM**，不是B站真实云端。
- 官方CLI v0.6.3校验下载后，whoami报告未登录；启动正式OAuth登录，平台返回“当前账号未在Toy CLI白名单内”。未上传包、未创建Toy、未提交审核。随后用户选择暂时跳过真实验证。
- 实际Toy预览、OpenID配置与授权、云榜/云存档、B站App内WebGL/Worker/音频、杀后台/重装/升级、物理跨设备、外部WSS：**NOT TESTED**。当前包未配置公开好友服务，该模式明确提示尚未开放。
- SDK没有公开事务/CAS或可靠账号变化事件，身份核对与云操作无法原子绑定；极端平台切号竞态与资料缓存仍不能从客户端完全消除。当前实现检查每次云操作前后，并在页面重新可见时核对身份。
- Web Locks、crypto.subtle、OpenID不足时，不启用账号云写入；访客与文件备份仍可用。云空间最多128键、每值1024字节，多设备/过大棋局可能耗尽；不删除其他设备腾空间。核心进度有空间时可单独留下小备份，但完整快照仍显示待同步。
- 本机存储被清理、容器阻止下载或云服务不可用时，最后未确认的变化仍可能丢失。清数据/换设备前须确认完整同步或保留导出文件。文件备份能否在B站App实际下载/选择也须实机验收。

# GitHub源码上传范围

本次上传的是可构建、可运行的游戏源码仓库：源码、测试、构建与维护脚本、文档、随包字体许可，以及完整运行WebP。使用README中的`npm ci`与构建命令生成运行产物。

宣传片分镜、宣传参考包及其ZIP位于本机`docs/promo/`，不属于游戏运行依赖，本次保留在本机并排除出Git。`node_modules/`、`dist/`、`dist-toy/`、`server-dist/`、`.local/`、测试临时输出、日志及真实`.env`同样不上传；`.env.example`只包含公开配置示例。玩家存档属于各自浏览器／Toy账号，不作为源码的一部分上传。

用户确认PNG绘制原稿完整保留在本机，不纳入公开仓库主分支；运行WebP、衣装、表情与CG不减。美术维护脚本与历史哈希清单保留，但复现原稿校验、重新导出或测量轮廓需要另备PNG原稿。含原稿的完整本机Git快照另存于`codex/source-with-original-art`分支，切勿将其作为本次公开上传分支推送。

此源码仓库与受50MB限制的Toy静态运行包是不同交付物。上传GitHub不等于发布Toy、部署网页、创建Release或完成真实平台验收。项目为成年AU同人作品，仓库没有新增第三方角色或素材的授权声明；字体许可随字体保留。

2026-10-24准备上传时，原仓库是无提交的`feat/wizard-chess`分支，且无远程地址。用户明确选择新建公开仓库`kallist/wizards-gambit`，并在大包传输超时后确认只上传完整运行源码、原稿留本机。最终公开初始化提交收录上述游戏文件，宣传资料、PNG原稿和本地测试证据保持本地；历史文档中“未提交／未上传”描述对应各自原交付时间。当前远程分支与提交以GitHub实际记录为准。

本轮保持React/Vite、共享棋规、Worker、现有Node好友服务及存档架构；没有API、数据库、依赖或游戏行为变更。敏感信息检查、构建、自动化测试与远程提交读回的原始收据仅保存在本机忽略目录`.local/github-upload/`。真实Toy／B站App／云、Docker与Hosted CI状态不因源码上传自动变为已验证。
